Panduan Penggunaan

1. Parquet Injector (Baru)

  • Pemrosesan kilat mengubah file CSV/XLSX berukuran raksasa langsung menjadi file database .parquet.
  • Dilengkapi instruksi filter kolom kustom untuk menyaring kolom yang hanya diperlukan.

2. Data Splitter

  • Memisahkan file hasil apex berdasarkan kolom CODING (Open, Closed, Return, Claim).

3. Split by Rows

  • Memecah file besar menjadi file kecil berdasarkan jumlah baris.

4. Data Merger

  • Menggabungkan ratusan file CSV/Excel menjadi satu file utuh.

5. Audio & Text

  • Audio to Text: Otomatis mendeteksi ucapan dan merubah ke teks.
  • Text to Audio: Membaca teks dengan intonasi natural pilihan bahasa.

6. Maps Scraper

  • Otomatis melengkapi data Google Maps (Lat/Long, Alamat) secara massal dari koordinat atau nama tempat via OpenStreetMap API.
